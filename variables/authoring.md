# Подстановки переменных: aheronVarsV1

Этот язык читает значения в текстовом поле через `{{ссылка}}`. Он сам не
вычисляет формулы, не создаёт переменные, не записывает данные и не даёт доступ
к проекту. Доступные значения и обработку отсутствующих значений определяет
блок или интеграция, которые выполняют подстановку.

## Области и пути

| Ссылка | Что выбирает |
| --- | --- |
| `{{score}}`, `{{subject.score}}` | Переменную контакта с техническим ключом score |
| `{{project.rate}}` | Общую переменную проекта rate |
| `{{project.id}}` | ID проекта запуска, а не переменную с ключом id |
| `{{demo.score}}` | Переменную интеграции со slug demo |
| `{{context.metadata.custom.total}}` | Поле metadata текущего контекста, если оно предоставлено |
| `{{integrationState.cursor}}` | Состояние текущей интеграции, если оно предоставлено |
| `{{subject.order.items.0.price}}` | Поле price первого элемента items объекта order у контакта |

Ключ — техническое имя, а не подпись в интерфейсе. Регистр значим. Пробелы
вокруг всей ссылки допустимы: `{{ subject.score }}`. Внутри каждого сегмента
разрешены только буквы Unicode, цифры, `_` и `-`; точка разделяет сегменты.
UUID укладывается в этот синтаксис, но поиск по UUID работает только там, где
владелец значений предоставляет такие псевдонимы.

Префиксы subject, project, context и integrationState зарезервированы.
Любой другой первый сегмент ссылки с точкой означает slug интеграции:
`{{order.total}}` НЕ читает поле total объекта контакта order. Для объекта
нужно `{{subject.order.total}}`. Наличие установленной интеграции не меняет
разбор ссылки. Если нужная область отсутствует, поиска в другой области нет.
Одиночный ключ `{{project}}` при этом остаётся переменной контакта project.

Дальнейшие сегменты читают свойства JSON-объекта или элементы JSON-массива.
Индексы массива начинаются с нуля, без ведущих нулей: `.0`, `.1`. Отрицательный
индекс, `.00`, выход за границы, отсутствующее свойство или путь через null
дают отсутствующее значение. Числовое имя свойства объекта читается буквально.
Синтаксиса `items[0]`, кавычек вокруг ключей, wildcard, фильтров и вычисляемых
индексов здесь нет. Ключи с точками или пробелами этим языком не адресуются
как буквальные ключи; их нельзя «экранировать» квадратными скобками.

## Текст и ошибки

В одном поле допустимо несколько ссылок и обычный текст. Строка подставляется
без кавычек; boolean — как true/false; null — как пустая строка; объект или
массив — как JSON. Число подставляется десятичной записью; точно декодированный
JSON-number не проходит через float64. Это не гарантия точной арифметики:
округление могло произойти до передачи значения парсеру. Раскрытие слишком
большой экспоненты ограничено; нечисловые NaN/Infinity не допускаются.

Отсутствие значения отличается от существующего null. SDK по умолчанию
возвращает ошибку для отсутствующего значения. Runtime может явно выбрать
пустую строку вместо него. Ошибка чтения источника при этом не превращается
в пустую строку. Ошибка синтаксиса или подстановки не возвращает частичный текст.

Незакрытое `{{`, пустое `{{}}`, вложенное `{{` или выражение внутри скобок,
например `{{score + 1}}`, — ошибки синтаксиса. Одиночные фигурные скобки и
закрывающие `}}` без открывающих остаются текстом. Специального escape для
буквального `{{` нет. Значение подставляется один раз: строка `{{other}}`,
прочитанная из переменной, не обрабатывается как вторая ссылка.

Подстановка сама по себе не экранирует JSON, URL или HTML. Конкретный клиент
может передать функцию escape: она применяется один раз к каждому значению,
но не к окружающему тексту. Не считай любой результат безопасным JSON/HTML
только потому, что использована подстановка.

## Исполняемые примеры

Ниже учебный набор значений и ожидаемых результатов, а не HTTP-запрос или
настройки блока. missingPolicy относится к вызову SDK: error — его стандартное
поведение, empty — явно разрешённая пустая строка. Эти примеры проверяются
тем же парсером и renderer, которые используют сервисы.

```json
{
  "values": {
    "projectId": "project-123",
    "subject": {
      "score": 10, "Score": 11, "enabled": true, "empty": null,
      "first-name": "Анна", "город": "Москва", "project": "literal-key",
      "nested": "{{score}}", "large": 9007199254740993,
      "order": {"items": [{"price": 1.5e2}]}
    },
    "project": {"score": 20, "id": "shadow"},
    "integrations": {"demo": {"score": 30}},
    "context": {"metadata": {"custom": {"total": 40}}},
    "integrationState": {"cursor": "next"}
  },
  "examples": [
    {"template": "{{score}} / {{subject.score}} / {{project.score}} / {{demo.score}}", "expected": "10 / 10 / 20 / 30"},
    {"template": "{{ subject.Score }}: {{first-name}}, {{город}}", "expected": "11: Анна, Москва"},
    {"template": "{{project.id}} / {{project}}", "expected": "project-123 / literal-key"},
    {"template": "{{subject.order.items.0.price}}", "expected": "150"},
    {"template": "{{context.metadata.custom.total}} / {{integrationState.cursor}}", "expected": "40 / next"},
    {"template": "{{enabled}}|{{empty}}|{{large}}", "expected": "true||9007199254740993"},
    {"template": "{{subject.order.items}}", "expected": "[{\"price\":1.5e2}]"},
    {"template": "{{nested}}", "expected": "{{score}}"},
    {"template": "1 + 2; {text}; }}", "expected": "1 + 2; {text}; }}"},
    {"template": "{{subject.order.items.00.price}}", "error": "missing"},
    {"template": "{{subject.order.items.-1.price}}", "error": "missing"},
    {"template": "{{subject.order.items.1.price}}", "error": "missing"},
    {"template": "{{empty.field}}", "error": "missing"},
    {"template": "{{subject.empty.field}}", "error": "missing"},
    {"template": "{{order.items}}", "error": "missing"},
    {"template": "{{unknown.score}}", "error": "missing"},
    {"template": "before{{missing}}after", "missingPolicy": "empty", "expected": "beforeafter"},
    {"template": "{{missing}}", "error": "missing"},
    {"template": "{{score + 1}}", "error": "syntax"},
    {"template": "{{subject.order.items[0].price}}", "error": "syntax"},
    {"template": "{{subject..score}}", "error": "syntax"},
    {"template": "before{{score", "error": "syntax"},
    {"template": "{{}}", "error": "syntax"},
    {"template": "{{ {{score}} }}", "error": "syntax"}
  ]
}
```
